Connect to this anoa

Every URL below is this browser's, with the token filled in. The token never leaves this page: it is read from ?token= in the address bar or typed here.

Where the token comes from: the line anoa: token ... in the log of the container or machine running anoa (docker logs <container>, or /tmp/anoa.log in an E2B sandbox). An anoa started without --auth-token needs none.
